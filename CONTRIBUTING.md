# Contributing

`dream` is deliberately tiny — one skill, one idea. Contributions that keep it
sharp are welcome.

**Good PRs**
- Tighten the wording of `skills/dream/SKILL.md` without adding bulk.
- Fix typos, broken links, or rendering issues.
- Port the skill to another agent's format (add it under a new folder, don't
  change the canonical one).

**Please don't**
- Turn the primer into a checklist or a procedure. The whole point is that it is
  a self-conception, not steps.
- Add dependencies or a build step. A skill is a folder with a `SKILL.md`.

Open an issue first for anything larger than a wording change. Keep commit
messages in English, imperative mood.
